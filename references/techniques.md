# 杀手数独技巧库

按"能解锁什么"排序，从狠到松。

## 1. 45法则多区域版

单区域（一宫/一行/一列=45）看不出来时，放大区域：

- 两宫 = 90、三宫带（横三条/竖三条）= 135
- 行+宫、列+宫 = 90 − 重叠的3格
- 五宫、五行等大军团照样可用，用 `killer45_scan.py` 全量扫描

心算技巧：笼子边加边减45，加完剩37，那 45−37=8 就是多出来的格。

## 2. 幽灵笼子（虚拟笼）

45法则剩下不止一格时，得到的是"这几格的和"——当成图上没画的隐形笼子套组合表：

- 剩2格、和8 → {1,7}{2,6}{3,5} → 这两格都不能是 4/8/9
- **注意**：幽灵笼子的格子之间没有"不重复"约束（除非恰好同行/列/宫），套组合表时互斥条件要按真实位置算，否则会把合法关系误报成矛盾

高手的中盘就是滚这个循环：45法则造隐形笼 → 组合表拆它 → 拆出的候选喂下一个45法则。

## 3. 笼拆分

和很大的5格、6格笼子组合几十种没法直接看。跨宫时用边界算出宫内部分和，当迷你笼分析——大笼变两个小笼。

## 4. 组合交集（日常主力）

每看一个笼子过三道筛子：笼子的合法组合 ∩ 行列宫已有数字 ∩ 格子自身候选。

## 5. 笼出指向

某数字在笼内所有可能位置都落在同一行/列 → 该行/列其他格删掉此数。经典"区块"技巧在笼子里更容易触发。

## 6. 笼级笔记

格子上写组合对（如"14/23"，意为"不是1和4就是2和3"）不写散候选。组合死了连带走一半候选，比逐格重推快。

## 7. 开局顺序

四角宫扫45（角落笼子两头被墙堵着，不易乱铺）→ 标记唯一组合 → 才写候选。往往没动笔就白捡六七个数。

## 8. 经典技巧照样是主力

隐性唯一、显性/隐性数对、区块在杀手里照样天天用，算术和经典逻辑两条腿走路，别光埋头算术。

## 9. 技术坑（写代码时）

- 笼内数字可任意排列分配给格子：候选初始化必须用"组合数字并集"，组合过滤必须用二分匹配回溯，**不能**把升序组合按位置绑定格子，否则误判矛盾
- 混合区域（行+宫）有重叠格，用加权方程处理（重叠格系数=2）
- 高斯消元用分数运算（Fraction），浮点会出精度垃圾；消元时主元方程引入的新变量不能丢
- 删候选类招数（数对、指向）必须全部用完才允许落子，否则候选未收敛会落错子
- 笼内隐性唯一落子前必须确认"该数字出现在所有合法组合里"，只在部分组合出现的数字不能锁定位置
